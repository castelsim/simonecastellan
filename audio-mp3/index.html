    A cosa serve

    Un provino registrato dal telefono o un file esportato dal programma di montaggio pesa troppo per una mail. In MP3 pesa fino a dieci volte meno.

    Serve per mandare un ascolto, non per archiviare: per quello tieni l'originale.

    Domande

    Si sente peggio?

    Un po', ma su un ascolto in cuffia o al telefono non te ne accorgi. Se devi mandare il file al mastering, manda l'originale.

    Quali file accetta?

    WAV, AIFF, M4A, FLAC, OGG e anche la traccia audio di un video. Se il tuo browser sa aprirlo, qui si converte.

    Posso convertirne più di uno?

    Sì, trascinali tutti insieme. Vanno in fila e alla fine li scarichi uno per uno o tutti in un colpo. Se uno non si converte, gli altri proseguono.

    I file salgono da qualche parte?

    No. Il motore che converte gira dentro il browser, sul tuo dispositivo. I file non escono di lì, nemmeno verso di me.
